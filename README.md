# 💻 Algoritmos — Uniara

Exercícios em **linguagem C** das disciplinas de Algoritmos do curso de **Engenharia da Computação** da Uniara.

## Algoritmos II

| Pasta | Conteúdo |
|---|---|
| [`01-lista-10-03`](algoritmos-2/01-lista-10-03) | Lista completa: questões teóricas (passagem por valor × referência, ponteiros, `&` e `*`) e exercícios práticos por parte |
| [`02-lista-16-03`](algoritmos-2/02-lista-16-03) | `meuStrlen`: tamanho de string por referência, sem `<string.h>` |
| [`03-lista-4-structs`](algoritmos-2/03-lista-4-structs) | Exercícios com `struct` usando a biblioteca de entrada PSS |

## Como compilar

```bash
gcc arquivo.c -o programa
# nos exercícios da lista 4, junto com a biblioteca:
gcc ex1.c pss.c -o ex1
```

A biblioteca `pss.c/.h` é do Prof. Saulo Santos ([pss-library](https://github.com/Prof-Saulo_Santos/pss-library), licença BSD-3).
